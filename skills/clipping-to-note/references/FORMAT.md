# 成品版式规范

## frontmatter

```yaml
---
title: AI 辅助学习的六个方法
source: https://www.bilibili.com/video/BV1eGTj69EKB/
author: 通往AGI之路
published: 2026-07-02
created: 2026-10-20
tags: [clippings, bilibili, AI-学习]
original_title: 如何用 Claude 以 10 倍速度学习任何东西
---
```

| 字段 | 必填 | 内容 |
|---|---|---|
| `title` | 是 | 精简标题，与文件名、正文 `#` 标题一致 |
| `source` | 是 | 原始链接；没有链接时写剪藏文件路径 |
| `author` | 否 | 原作者或账号，剪藏没有就省略 |
| `published` | 否 | 原文或视频发布日期 `YYYY-MM-DD`，不知道就省略 |
| `created` | 是 | 整理日期 |
| `tags` | 是 | 来源标签保留剪藏原有的（`clippings`、`bilibili`、`web`），再追加 1-3 个按内容归纳的主题标签 |
| `original_title` | 否 | 剪藏原标题，原名与精简标题相同时省略 |

不要写入 `bvid`、`cid`、`subtitle_lang` 这类抓取过程的中间字段。

## 正文结构

```markdown
# 精简标题

> [!abstract] 摘要
> 三到五句话，说清这篇讲了什么、适合谁看、看完能拿到什么。

## 一、小节标题

正文段落。

### 1.1 更细的划分

只在单个小节超过三百字、或含多个并列要点时使用三级标题。

## 二、小节标题

| 做法 | 效果 |
|---|---|
| …… | …… |

## 相关笔记

- [[05 vibecoding/agent学习路线]]
```

### 标题层级

- 全文只有一个 `#`，紧跟摘要。
- 二级标题用中文数字："一、" "二、"，中间不要空行。
- 三级标题用阿拉伯数字："1.1" "1.2"。
- 层级不跳级，不出现没有二级标题兜底的三级标题。

### 摘要

放在一级标题之后、第一个二级标题之前，用 `> [!abstract] 摘要` 引用块。三到五句，从全文压缩，不要写成目录式的一句话列举。全文不足八百字时省略摘要，内容太短时摘要反而占篇幅。

### 表格

两列以上的对比、参数、步骤对照用表格。单一清单用无序列表。表格单元格里不要塞长段落。

### 结尾

只保留两个可选小节：

- `## 来源`：只写 frontmatter 里没有的信息。链接已经在 `source`、作者已经在 `author` 时，正文不再重复；属性里缺哪项就只补哪项，例如视频只补一行"原视频：标题（作者）"。属性已经覆盖全部信息时整节删掉。
- `## 相关笔记`：最多三五个 `[[...]]` wikilink，指向库里确实存在、内容相关的笔记。没有就整节删掉，不要留空标题。

属性里有的信息不在正文重复，是这两节的统一规则。不写"要点回顾""总结"这类收尾小节。

## 文字规范

- 简体中文，专有名词保留英文原词（Claude、API、Bilibili）。
- 动宾结构完整，写"用新版本替换旧文件"，不写"换文件"这类缩略说法。
- 句子短，一句只说一件事；不用"赋能的""闭环""抓手"这类空词。
- 数字用阿拉伯数字，量词和单位写全。
- 正文不出现"原字幕是……""这里我改成了……"这类修改痕迹，也不写整理过程。
- 不出现时间戳、`00:00` 之类的定位标记。
