# 剪藏转笔记

把一份本地剪藏文件提炼成结构清晰、可以直接读的中文笔记，原件保持不动，成品另存到主题目录。

## 流程

### 1. 读剪藏，判类型

读整个文件，包括 frontmatter。按正文形态归入三档：

| 类型 | 特征 | 处理方式 |
|---|---|---|
| 视频字幕 | 每行带 `mm:ss` 时间戳，短句分行，口语语序 | 完整重组：改写、合并、分节 |
| 干净网页 | 已是规整 Markdown，标题、段落、列表齐全 | 只做结构化和摘要，不改写原句 |
| 脏网页 | 混着 `<div>`、`<span>`、导航、广告、“相关推荐” | 先清洗成干净正文，再按上一档处理 |

判断不准时按更难的那一档做，成品偏干净比偏脏好。

### 2. 确认素材够不够

素材不足一轮重写时停下：正文为空、只有标题加链接、付费墙截断、视频没有字幕且只有播放器。这时直接告诉用户缺什么、建议怎么办，等用户决定，不联网补抓。

### 3. 提炼正文

先读完再动手，不要读一段写一段。产出前在脑子里过一遍：这篇文章讲了哪些观点，哪些是例子，哪些是过渡废话。

- **视频字幕**：按内容重排成小节，合并重复表达，删掉“然后呢”“所以说”“你会发现”这类纯过渡句。保留全部实质观点、例子、数字、清单和提问句式。同音错字按上下文改正（`cloud` → Claude、`we two a g i` → 通往AGI之路），改完通读一遍确认语义没跑偏。
- **干净网页**：句子保持原样，只补结构、压摘要、去掉与主题无关的段落。
- **脏网页**：先删掉标签包裹的导航、侧栏、广告、评论、“相关文章”、订阅提示，再合并被标签切碎的行。

### 4. 生成标题

原标题多半带“如何”“任何”“一个”“这期就讲”这类虚词、书名号和问号。压成 8-16 字，保留主题词和核心结构词，不要意译过头。

原标题《如何用 Claude 以 10 倍速度学习任何东西》→《AI 辅助学习的六个方法》。

正文 `#` 标题、frontmatter 的 `title` 都用精简标题，不带序号；原标题存进 `original_title`。

### 5. 选主题目录

看成品内容属于哪个主题，选库里已有的目录，例如算法、mac 操作、vibecoding、方法论、Python 基础。没有合适主题时，新建一个“编号 + 中文名”的目录，编号接现有最大值（当前是 `05 Python 基础`，下一个是 `06`）。

库里所有主题目录都用两位数编号，目录内的笔记也按同样规则排序列，两级编号都要遵守：

- 文件名格式为 `NN.标题.md`，`NN` 是两位数（`01.`、`02.`……`10.`），点号紧跟数字、不带空格。
- 新笔记编号接该目录现有最大值，保持阅读顺序连续；中间插入时整体重排编号，不留空号。
- 序号只出现在文件名里，frontmatter 的 `title` 和正文 `#` 标题保持纯标题。
- 清掉标题里的 `/ \ : * ? " < > |` 这些字符。
- 该目录已存在同标题笔记时改成 `NN.标题-2.md`，不要覆盖。

### 6. 按规范写文件

frontmatter 字段和正文版式都照 [`references/FORMAT.md`](references/FORMAT.md) 写。写之前读它，不要凭记忆。

正文末尾的 `## 来源` 只补剪藏属性里没有的信息。链接已经写进 `source`、作者已经写进 `author` 时，正文不再重复；这些信息属性里全都有，就整节删掉。

### 7. 机械自检

对刚写完的文件跑一遍检查，不通过就改到通过再交付：

```bash
f=成品路径
grep -nE '^`?[0-9]{2}:[0-9]{2}' "$f"                                  # 应为空：没有残留时间戳
grep -nE '<(div|span|iframe|script|nav|aside)' "$f"                   # 应为空：没有残留 HTML 标签
grep -c '^# ' "$f"                                                    # 应为 1：只有一个一级标题
python3 - "$f" <<'PY'
import sys, yaml
text = open(sys.argv[1], encoding='utf-8').read()
meta = yaml.safe_load(text.split('---')[1])
for key in ('title', 'source', 'tags'):
    assert meta.get(key), f'缺少 {key}'
h1 = [l[2:].strip() for l in text.splitlines() if l.startswith('# ')]
assert len(h1) == 1 and h1[0] == meta['title'], f'一级标题与 title 不一致：{h1}'
print('frontmatter ok')
PY
```

每条命令的输出与注释里的期望一致才算通过。

### 8. 交付

回复里一句话交代成品路径和选这个目录的理由；有多篇时再列一行“成功 N 篇、跳过 M 篇及原因”。素材里辨认不准的推断单独说一句，正文不留痕迹。

一次给多篇时逐篇独立处理、逐篇落盘，单篇失败不阻塞其余。
